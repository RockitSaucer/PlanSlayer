# V8.0.34

## New list category on type chips + same event type

- Adding a category on an item now puts that type at the **top** of the Show all / type chips so you can sort by it immediately.
- The new category is saved for the **event type** (not just this one list).
- Any other list or event with the same event type gets it in the category dropdown next time.
- Personal lists (no event type) still share one global category list.
