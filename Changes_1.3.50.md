# PlanSlayer V1.3.50

## Hunt parity — colors & location share

1. **My Color / marker colors** — same Hunt presets (black, white, blue, red, yellow + amber/green/purple seeds; last 3 slots hold custom wheel picks).
2. **Color UI** — circular **dots** + small **Color wheel** button (no tab grid). Used for name color, pin color, and location-marker style picker.
3. **GPS button** — Hunt green My location control.
4. **Tap location marker** (you or a member) — map snaps to them and shows facing direction.
5. **Share location** — immediate snap + first broadcast; position ping **~20s**; heading refresh **~5s**; GPS keeps running when the tab is backgrounded; last known stays on the event after stop/close so peers still see where you were.
